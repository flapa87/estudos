Conceitos de Internet e Intranet - 20 Questões Inéditas (CEBRASPE/FGV/FCC)

Questão 1

(CEBRASPE - Estilo INSS) Sobre o conceito de Internet, analise: A Internet é uma rede de computadores de alcance mundial que utiliza protocolos específicos para comunicação. Considerando suas características, assinale a alternativa correta:

A A Internet é uma rede privada de computadores, acessível apenas por instituições governamentais ❌
B A Internet é uma rede pública mundial de computadores que utiliza o protocolo TCP/IP para comunicação entre dispositivos ✓
C A Internet funciona exclusivamente através de cabos de fibra óptica, não permitindo conexões sem fio ❌
D A Internet é uma rede fechada que exige licença especial para acesso, sendo controlada por uma única empresa ❌
E A Internet é sinônimo de World Wide Web (WWW), sendo ambos termos intercambiáveis para o mesmo conceito ❌
Resposta Correta: Letra B
Conceito de Internet: A Internet é uma rede pública mundial de computadores interconectados que utilizam o conjunto de protocolos TCP/IP (Transmission Control Protocol/Internet Protocol) para comunicação.

Características fundamentais:
• Natureza pública: Acessível a qualquer pessoa com conexão
• Protocolo TCP/IP: Protocolo padrão de comunicação
• Arquitetura descentralizada: Não possui controle centralizado
• Meios de transmissão: Cabos, fibra óptica, satélite, redes sem fio (Wi-Fi, 4G, 5G)

Diferença importante: Internet ≠ WWW. A World Wide Web (WWW) é apenas um dos serviços disponíveis na Internet (junto com e-mail, FTP, streaming, etc.).

⚠️ Diferença crucial:
Internet: Infraestrutura física e lógica de redes (hardware + protocolos)
WWW: Sistema de documentos hipertexto acessíveis via navegador
Protocolo: TCP/IP é o padrão universal
Acesso: Público e global

Questão 2

(FGV - Adaptada) Sobre o conceito de Intranet, assinale a alternativa correta:

A Intranet é uma rede pública de alcance mundial, semelhante à Internet, porém mais rápida ❌
B Intranet utiliza protocolos diferentes da Internet, como o IPX/SPX em vez do TCP/IP ❌
C Intranet é uma rede privada interna de uma organização que utiliza os mesmos protocolos da Internet, mas com acesso restrito aos colaboradores autorizados ✓

E Intranet e Internet são termos sinônimos, podendo ser usados indistintamente ❌
Resposta Correta: Letra C
Conceito de Intranet: É uma rede privada interna de uma organização que utiliza a mesma tecnologia da Internet (protocolos TCP/IP, navegadores, páginas web) para compartilhar informações e serviços entre seus colaboradores.

Características principais:
• Acesso restrito: Apenas funcionários autorizados
• Segurança: Maior controle e proteção de dados
• Protocolos: TCP/IP (mesmos da Internet)
• Infraestrutura: Pode ser física (cabeada) ou wireless
• Finalidade: Comunicação interna, gestão de documentos, sistemas corporativos

Exemplos de uso: Portal do funcionário, sistema de RH, comunicados internos, biblioteca digital corporativa.

📊 Internet vs Intranet:
Internet: Pública, acesso irrestrito, alcance global
Intranet: Privada, acesso restrito, alcance local/organizacional
Protocolos: Ambas usam TCP/IP
Segurança: Intranet é mais controlada
Custo: Intranet não paga por tráfego de dados

Questão 4

(FCC - Adaptada) Sobre o protocolo TCP/IP, analise as assertivas:

I. O TCP (Transmission Control Protocol) é responsável pelo controle de transmissão, garantindo a entrega ordenada e sem erros dos pacotes de dados
II. O IP (Internet Protocol) é responsável pelo endereçamento e roteamento dos pacotes entre redes
III. O TCP/IP é um protocolo proprietário da Microsoft, não sendo utilizado em outros sistemas operacionais
IV. O modelo TCP/IP possui quatro camadas: Aplicação, Transporte, Internet e Interface de Rede

Estão corretas:

A I e II apenas ❌
B I, II e III apenas ❌
C II e IV apenas ❌
D I, II e IV apenas ✓
E Todas as assertivas ❌
Resposta Correta: Letra D
Protocolo TCP/IP: Conjunto de protocolos padrão da Internet, não proprietário, utilizado universalmente.

I. CORRETO: O TCP (Transmission Control Protocol) é orientado à conexão, garante entrega ordenada, controle de fluxo e correção de erros.

II. CORRETO: O IP (Internet Protocol) cuida do endereçamento lógico (endereços IP) e do roteamento entre redes diferentes.

III. ERRADO: O TCP/IP é um padrão aberto (open standard), não é proprietário da Microsoft. É utilizado por todos os sistemas operacionais (Windows, Linux, macOS, Android, iOS).

IV. CORRETO: O modelo TCP/IP possui 4 camadas:
• Aplicação: HTTP, FTP, SMTP, DNS
• Transporte: TCP, UDP
• Internet: IP, ICMP, ARP
• Interface de Rede: Ethernet, Wi-Fi

📊 Camadas do TCP/IP:
4. Aplicação: Interface com o usuário (navegador, e-mail)
3. Transporte: Controle de entrega (TCP/UDP)
2. Internet: Endereçamento e roteamento (IP)
1. Interface: Hardware de rede (placa de rede)
Importante: Padrão aberto e universal

Questão 5

(CEBRASPE - Estilo INSS) Sobre endereçamento IP, julgue o item: O endereço IP 192.168.1.1 é um exemplo de endereço IP público, acessível diretamente pela Internet.

A Certo ❌
B Errado ✓
Resposta Correta: Errado
Erro! O endereço 192.168.1.1 é um endereço IP privado, não público.

Faixas de IP privado (RFC 1918):
• Classe A: 10.0.0.0 a 10.255.255.255 (10.0.0.0/8)
• Classe B: 172.16.0.0 a 172.31.255.255 (172.16.0.0/12)
• Classe C: 192.168.0.0 a 192.168.255.255 (192.168.0.0/16)

Características do IP privado:
• Usado em redes locais (LAN)
• Não é roteável na Internet pública
• Requer NAT (Network Address Translation) para acesso externo
• Pode ser usado por qualquer pessoa sem registro

IP Público: Endereço único na Internet, atribuído pelo ISP (provedor), roteável globalmente.

⚠️ Correção:
192.168.1.1: IP privado (Classe C)
Uso: Roteadores residenciais, redes internas
Acesso externo: Requer NAT
IP Público: Exemplo: 201.45.67.89
Base legal: RFC 1918

(FGV - Adaptada) Sobre os protocolos HTTP e HTTPS, assinale a alternativa correta:

A HTTP e HTTPS são protocolos de transferência de arquivos entre computadores, semelhantes ao FTP ❌
B HTTPS é uma versão mais antiga do HTTP, sendo substituído gradualmente ❌
C HTTPS é a versão segura do HTTP, utilizando criptografia SSL/TLS para proteger a comunicação entre navegador e servidor ✓
D HTTP utiliza a porta 443 por padrão, enquanto HTTPS utiliza a porta 80 ❌
E Tanto HTTP quanto HTTPS garantem criptografia de ponta a ponta por padrão ❌
Resposta Correta: Letra C
HTTP (HyperText Transfer Protocol): Protocolo de transferência de hipertexto, usado para comunicação entre navegador e servidor web. Não possui criptografia.

HTTPS (HTTP Secure): Versão segura do HTTP que utiliza SSL/TLS (Secure Sockets Layer/Transport Layer Security) para criptografar a comunicação.

Portas padrão:
• HTTP: Porta 80
• HTTPS: Porta 443

Indicadores visuais:
• HTTPS mostra um cadeado na barra de endereço
• HTTP mostra "Não seguro" em alguns navegadores

Importância: HTTPS protege dados sensíveis (senhas, cartões de crédito, dados pessoais) contra interceptação (ataques "man-in-the-middle").

📊 HTTP vs HTTPS:
HTTP: Não criptografado, porta 80, vulnerável
HTTPS: Criptografado (SSL/TLS), porta 443, seguro
Indicação: Cadeado no navegador = HTTPS
Uso atual: HTTPS é padrão obrigatório
SEO: Google prioriza sites HTTPS

Questão 7

(CEBRASPE - Estilo INSS) Sobre o DNS (Domain Name System), julgue o item: O DNS é um sistema de tradução que converte nomes de domínio legíveis por humanos (como www.inss.gov.br) em endereços IP numéricos (como 189.9.9.99), permitindo que os usuários acessem sites sem precisar memorizar números.

A Certo ✓
B Errado ❌
Resposta Correta: Certo
DNS (Domain Name System): Sistema de nomes de domínio que funciona como uma "agenda telefônica" da Internet, traduzindo nomes amigáveis em endereços IP.

Funcionamento:
1. Usuário digita www.inss.gov.br
2. Navegador consulta servidor DNS
3. DNS retorna o endereço IP correspondente
4. Conexão é estabelecida com o servidor

Estrutura hierárquica do domínio:
• Raiz (.): Servidores raiz
• TLD: .br, .com, .gov, .org
• Domínio: inss.gov.br
• Subdomínio: www.inss.gov.br

Importância: Sem o DNS, seria necessário memorizar números IP (ex: 189.9.9.99) para acessar cada site.

📊 DNS na prática:
Entrada: www.google.com
Saída: 142.250.80.46
Função: Resolução de nomes
Porta: 53 (UDP/TCP)
Analogia: Agenda telefônica da Internet

Funções do ISP: Atribuir IP, roteamento, DNS, suporte técnico.

E O cache armazena cópias temporárias de páginas web, imagens e arquivos no computador do usuário para acelerar o carregamento em visitas futuras ao mesmo site ✓
Resposta Correta: Letra E
Cache do Navegador: Área de armazenamento temporário onde o navegador guarda cópias de recursos (páginas HTML, imagens, CSS, JavaScript) dos sites visitados.

Objetivo: Acelerar o carregamento de sites já visitados, pois o navegador recupera arquivos do cache local em vez de baixar novamente do servidor.

Vantagens:
• Velocidade: Carregamento mais rápido
• Economia de banda: Menos consumo de dados
• Menor carga no servidor: Menos requisições

Desvantagens:
• Pode exibir conteúdo desatualado (solução: Ctrl+F5 para recarregar sem cache)
• Ocupa espaço em disco

Diferença de cookies: Cache = arquivos do site; Cookies = dados de preferência/rastreamento.

Objetivo: Velocidade de carregamento
Conteúdo: Imagens, CSS, HTML, JS
Local: Disco rígido do usuário
Limpeza: Pode ser feita manualmente
Atalho: Ctrl+F5 (ignorar cache)

(CEBRASPE - Estilo INSS) Sobre phishing, julgue o item: O phishing é um tipo de ataque cibernético que utiliza e-mails fraudulentos ou sites falsos que imitam instituições legítimas para enganar usuários e obter informações confidenciais como senhas e dados bancários.

A Certo ✓
B Errado ❌
Resposta Correta: Certo
Phishing (Pescaria): Ataque de engenharia social que utiliza comunicações fraudulentas (e-mails, mensagens, sites) disfarçadas de fontes confiáveis para roubar dados sensíveis.

Características:
• Imitação: Sites/e-mails idênticos aos originais
• Urgência: Mensagens que criam pressa ("sua conta será bloqueada")
• Links maliciosos: Endereços similares ao legítimo (ex: banc0.com vs banco.com)
• Anexos infectados: Arquivos com malware

Variações:
• Spear phishing: Direcionado a alvos específicos
• Whaling: Direcionado a executivos/alta direção
• Smishing: Via SMS
• Vishing: Via ligação telefônica

Prevenção: Verificar remetente, não clicar em links suspeitos, usar autenticação de dois fatores.

📊 Phishing:
Tipo: Ataque de engenharia social
Objetivo: Roubar dados confidenciais
Meios: E-mail, sites falsos, SMS
Característica: Imitação de instituições
Prevenção: Verificação de fonte, 2FA
Similar: Spear phishing, whaling, smishing

Questão 20

(CEBRASPE - Estilo INSS) Sobre os conceitos de Internet e Intranet, analise as assertivas:

I. Uma Intranet pode utilizar a infraestrutura física da Internet para conectar filiais remotas através de VPN
II. O protocolo TCP/IP é o padrão tanto para Internet quanto para Intranets modernas
III. Um servidor web (Apache, IIS, Nginx) pode hospedar sites tanto na Internet quanto em uma Intranet
IV. A principal diferença entre Internet e Intranet é a tecnologia utilizada, sendo a Intranet baseada em protocolos proprietários diferentes

Estão corretas:

A I e II apenas ❌
B I, II e III apenas ❌
C II e IV apenas ❌
D I, II e III apenas ✓
E Todas as assertivas ❌
Resposta Correta: Letra D
Conceitos Integrados de Internet e Intranet:

I. CORRETO: VPN sobre Internet é uma prática comum para conectar filiais à Intranet corporativa de forma segura.

II. CORRETO: O TCP/IP é o protocolo padrão universal, usado tanto na Internet pública quanto em Intranets privadas.

III. CORRETO: Servidores web (Apache, IIS, Nginx) são agnosticos quanto à rede - podem servir conteúdo tanto na Internet quanto em Intranets.

IV. ERRADO: A diferença não é tecnológica (ambas usam TCP/IP, HTTP, HTML), mas sim de acesso e escopo: Internet é pública/global; Intranet é privada/restrita.

📊 Resumo Internet vs Intranet:
Tecnologia: Idêntica (TCP/IP, HTTP, HTML)
Diferença: Acesso (público vs restrito)
Conexão remota: VPN sobre Internet
Servidores: Mesmos softwares
Protocolos: Padrões abertos (não proprietários)
Segurança: Maior controle na Intranet
